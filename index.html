Using glTF Separate export? Blender's "glTF Separate (.gltf + .bin + textures)" format produces model.gltf, model.bin, and one or more image files (e.g. texture_0.jpg). All of these must be uploaded to the same folder in your repo — the .gltf file references the .bin and textures by relative path, so if any of them are missing or in a different folder, the model will fail to load (usually a silent blank viewer, or a console 404 for the .bin/texture file).

Note: this needs to be opened on an actual phone (Android with ARCore, or iOS 12+) for AR to launch — desktop only shows a 3D preview.
